
# Customer Purchase Data Analysis

## Project Overview
This project focuses on analyzing customer purchase data using Python. It demonstrates data collection, data cleaning, exploratory data analysis (EDA), preprocessing, and feature engineering.

## Objectives
- Import data from CSV, JSON, and SQLite.
- Understand and explore customer purchase data.
- Perform exploratory data analysis.
- Handle missing values and outliers.
- Process date and time variables.
- Encode categorical variables.
- Apply feature scaling.
- Perform feature engineering.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### 1. Data Import
- Import CSV files
